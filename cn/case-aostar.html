00 — 项目概述

一套设计规范，六个互联系统

「快乐老家」是《奥星热浪》的核心玩法。玩家在这里建造房间、种植作物、制作道具、烹饪食物，并照料AI伙伴：这一切共同构成一个持续运转的共享世界。设计挑战在于：让所有系统在视觉和交互上保持统一、易于学习，同时不让玩家感到负担过重。

我完整输出了《快乐老家交互设计规范》：一份覆盖UI行为规则、组件规格、状态定义及各系统交互模式的设计基准文档。每一个交互都需要同时服务于新手玩家和资深玩家两种心智模型。

// 设计规范目录：横跨6大系统、30余个子章节的完整交互指南。

01 — 通用家园

家园通用层：HUD信息架构

家园体验的最上层负责处理与3D世界共存的常驻UI元素：任务追踪、光仔交互按钮、导航指示及情境提示。核心挑战是在不遮挡世界的前提下保持画面可读。

我制定了多提示同时显示的优先级规则、基于距离的可见性逻辑，以及三级警示系统（L1/L2/L3）：根据光仔状态决定信息以何种紧迫程度呈现给玩家。

// 通用家园HUD：任务/订单追踪器、光仔交互按钮、建造快捷入口及距离提示指示器。

// 三级警示系统：L3紧急（光仔晕倒）、L2注意（光仔梦游）、L1普通（基础交互提示）。

// 家具交互状态：功能家具（制作台、烹饪台）与光仔家具（床、椅子）的远近距离可见性规则。

// 距离触发交互：家具标签与操作选项仅在玩家靠近到可操作范围内时才会显示。

// 光仔状态：根据玩家距离及情绪状态动态切换的光仔显示层级。

// 光仔气泡规则：触发条件、优先级叠加、按需求类型（能量/饥食/心情）区分颜色编码。

// 临时气泡显示：光仔完成动作或需要即时关注时触发的短时反馈。

// 提示优先级：种植类提示（最高）→ 家具交互提示 → 光仔状态提示（最低），避免信息过载。

// 优化前后对比：左：当前状态（提示堆叠混乱）；右：基于优先级的整洁布局。

// 种植交互：受虫害影响、浇水、收获三种状态，配合距离感应工具显示逻辑。

02 — UI交互规则

UI交互规则：设计系统的骨架

本章节定义了贯穿所有家园系统的通用交互语言：触控目标尺寸、操作面板行为、状态反馈模式、弹窗与确认流程、错误处理及输入控件规范。

无论视觉大小如何，所有触控目标最小触控区域统一设定为108×108px，确保在各种设备尺寸下的可及性。操作面板在选择工具后自动收起，并记忆上次使用的标签，减少重复导航操作。

// 控件规范：可视尺寸最小80×80px，触控区域最小108×108px，统一应用于所有可交互元素。

// 操作面板：情境感知标签（工具 / 种植 / 其他），根据靠近的可交互物体自动切换。

// 操作类型：默认、可操作（金色光圈）、无法操作（红色）。工具状态一目了然。

// 可操作类型矩阵：可交互、可取消、无法操作三种状态及对应视觉反馈规则。

// 弹窗系统：六种对话框类型：编辑数量、材料需求、确认提示、地块解锁、物品转移及中断警告。

// 家园等级进度条：可提升状态带视觉脉冲动效。提示系统涵盖错误、成功及状态通知三类场景。

03 — 光仔系统

光仔系统：大规模AI行为的可视化设计

光仔是在家园中生活、工作并产生需求的AI伙伴。单个玩家最多可同时管理10只光仔，每只光仔都有独立的状态、属性和任务队列。我设计了完整的管理界面：从光仔名单到个人属性面板、对话流程及订单系统。

核心挑战是：让AI行为对玩家透明可信，同时不暴露过于复杂的底层逻辑。属性展示、情绪状态指示以及光仔对话选项，都需要在恰当的时机传递恰当的信息量。

// 光仔管理面板：老家/背包双区名单、筛选系统、个人属性面板与管理/简历双标签。

// 属性 & 特性：光仔数值、特性标签及获得界面，含新角色引导流程展示。

// 光仔对话：家园光仔与随行光仔根据所处情境与位置提供不同的对话选项。

// 光仔交互：核心属性展示、道具工具入口、情境化对话选择（按光仔类型动态变化）。

// 光仔订单系统：订单状态（待接取/进行中/已完成）、每日刷新规则及光仔互助站界面。

// 自选提交：玩家主动交付物品的流程，含材料匹配界面及NPC对话整合。

04 — 种植系统

种植系统：将种植的复杂性化繁为简

种植系统贯穿种子购买、作物生长阶段、收获、烹饪到储存的完整资源循环。每个阶段都有独特的视觉状态和交互提示，需要在繁忙的3D环境中做到清晰易读。

// 种植状态矩阵：空地 → 播种 → 生长期（良好/虫害/缺水）→ 收获。各阶段可操作与不可操作工具状态对应。

// 种子商店：按光仔类型筛选，购买状态涵盖：默认、钱不足、有上限、售罄、已锁定等级、已锁定NPC。

// 烹饪台：菜谱卡片、星级成长路径、材料需求，以及光仔协助烹饪时的特殊状态。

// 储物家具：不同家具类型及容量状态下的储物界面规范。

// 收获品质变体：作物卡片展示稀有度等级、光仔能力影响及品质概率显示。

// 收获视觉反馈：提示徽章从「普通」到「超级传说」的品质升级，配合粒子特效呈现。

05 — 建造系统

建造系统：家具、制作合成与房间逻辑

建造系统允许玩家放置家具、制作道具，并随进度解锁新地块和房间。我设计了制作台界面、物品提示系统、放置逻辑及房间信息面板，确保系统能从初始地块平滑扩展至完整发展的家园。

// 制作台：物品预览、配方提示、材料需求清单及一键制造按钮。

// 放置逻辑：家具负载显示、功能家具上限提示，以及家具放置/移动/旋转/收回操作界面。

// 放置操作：放置/移动/旋转/取消/收回操作按钮，配合绿色（可放置）、红色（不可放置）颜色反馈。

06 — 进阶系统

进阶系统：解锁一个不断成长的世界

随着玩家深耕家园，他们将逐步解锁新地块、家具升阶和工具改进。进阶系统通过等级地图、升级预览及升级成功的动效庆典，让每一次成长都充满成就感。

// 种子包商店状态矩阵：跨光仔、种植、服装、家具四类种子包的默认、钱不足、有上限、售罄、等级锁定、NPC锁定全状态展示。

// 愉悦等级：含当前/下一级预览、解锁内容列表、升级奖励及升级成功动效庆典的完整进阶面板。
